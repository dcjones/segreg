# Segreg

Cell segmentation aware regression (and other tools for assessing missegmentation risk).

## Usage

Segreg performs negative binomial regression, regressing estimated gene
expression on arbitrary covariates. Unlike a typical regression framework,
segreg takes into to account segmentation uncertainty to avoid making
high-confidence calls in cases that might be explained by leakage or
missegmentation.

Input to the regression model is a SpatialData or AnnData object generated by
[proseg](https://github.com/dcjones/proseg), and a regression formula that's
parsed by [patsy](https://patsy.readthedocs.io/en/latest/formulas.html), which references
columns in the AnnData objects `obs` table. For example:

```python
from segreg import Regression

reg = Regression(adata, "~ 0 + C(cell_type) + C(cell_type):exposure")
reg.fit(device="cuda")
coefs = reg.get_regression_coefficients()
```

Here the formula regresses on cell type and the interaction between cell type
and an "exposure" measurement, which may be something like proximity to
particular feature or cell type. The `0` in the formula excludes an intercept
term, which would be redundant here.
